
WebGuard
A unified developer platform to safeguard the web using powerful encryption. 
WebGuard is a web application designed to provide developers an integrated platform to protect web applications from a variety of security threats.
Its key target is to defend against:
1.SQL Injection
2.Cross-Site Scripting (XSS)
3.Cookie & Session Hijacking
4.Phishing
5.DDoS
6.Malware

It has been published in international academic journal which is called International Academic Press.

Technology used:
Frontend:
React, Bootsrap, tailwind 
Backend:
Python(MLModel),Express js, Node js, MongoDB ,Firebase
